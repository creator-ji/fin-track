# FinTrack

Консольное backend-приложение для управления личными финансами на **Java 17** (курс ООП).  
Пользователи могут регистрироваться, учитывать доходы и расходы, задавать бюджеты по категориям, смотреть статистику, сохранять данные в файл и переводить деньги между кошельками.

Внешние библиотеки **не используются** — только стандартная библиотека Java и Maven для сборки.

## Требования

- JDK 17+
- Apache Maven 3.9+

Проверка окружения:

```bash
java -version
mvn -version
```

## Быстрый старт

```bash
git clone <url-репозитория>
cd fin-track
mvn compile exec:java
```

Сборка JAR:

```bash
mvn package
java -jar target/fin-track-1.0-SNAPSHOT.jar
```

Данные пользователей сохраняются в каталог `data/` (`*.wallet`).

## Как пользоваться

1. Запустите приложение (`mvn compile exec:java`).
2. Зарегистрируйте пользователя: `register`.
3. Войдите: `login` — кошелёк загрузится из файла (если уже был сохранён).
4. Добавляйте доходы (`income`), расходы (`expense`), бюджеты (`budget`).
5. Смотрите итоги: `balance`, `budgets`, `stats`.
6. При необходимости сохраните отчёт: `report` → `file`.
7. Для перевода другому пользователю: `transfer` (получатель должен быть зарегистрирован).
8. Выход: `exit` — данные текущего пользователя сохраняются на диск.

## Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `register` | Регистрация нового пользователя (логин + пароль) |
| `login` | Вход; загрузка кошелька из `data/<login>.wallet` |
| `whoami` | Показать текущего пользователя |
| `logout` | Выйти из аккаунта с сохранением кошелька |
| `income` | Добавить доход (категория, сумма) |
| `expense` | Добавить расход (категория, сумма); оповещения о лимитах |
| `budget` | Установить бюджет по категории расходов |
| `balance` | Баланс, общие доходы и расходы |
| `budgets` | Бюджеты и оставшийся лимит по категориям |
| `stats` | Полный отчёт в терминал |
| `categories` | Подсчёт по нескольким категориям (через запятую) |
| `report` | Вывод отчёта в терминал (`console`) или в файл (`file`) |
| `transfer` | Перевод другому пользователю по логину |
| `help` | Краткая справка по командам |
| `exit` / `quit` | Сохранить данные и завершить работу |

## Соответствие ТЗ

- Хранение данных в памяти во время работы + сохранение кошелька в файл при выходе / logout
- Авторизация нескольких пользователей по логину и паролю
- Доходы, расходы, категории, бюджеты на категории расходов
- Кошелёк привязан к пользователю (операции + бюджеты)
- Статистика: общие суммы и по категориям, остаток бюджета
- Вывод в терминал и в файл
- Подсчёт по нескольким выбранным категориям; уведомление, если категория не найдена
- Валидация ввода
- Оповещения: превышен бюджет категории; расходы превысили доходы
- Цикл команд с выходом
- Дополнительно: переводы между кошельками (расход у отправителя, доход у получателя)

```bash
mvn -q compile
```

Ожидаемые ключевые значения в `stats`:

- общий доход: `63000.0`
- зарплата: `60000.0`
- общие расходы: `8300.0`
- Еда: лимит `4000.0`, остаток `3200.0`
- Развлечения: остаток `0.0`
- Коммунальные услуги: остаток `-500.0` (оповещение о превышении)

### 3. Персистентность

1. Создайте операции, выполните `exit`.
2. Снова запустите приложение, сделайте `login` тем же пользователем.
3. `balance` должен показать сохранённые суммы.

### 4. Перевод

```text
register
bob
secret
login
alice
secret
transfer
bob
1000
logout
login
bob
secret
balance
```

У `bob` должен появиться доход `1000` в категории `Перевод`.

### 5. Валидация и ошибки

- пустой логин/пароль → сообщение об ошибке;
- повторная регистрация того же логина → ошибка;
- неверная сумма (`abc`, `0`, `-1`) → ошибка;
- `categories` с несуществующей категорией → «Категории не найдены»;
- перевод себе / несуществующему пользователю → ошибка.
